## Help Desk Scenarios

### Scenario 1: User Cannot Connect to the Internet

**Problem: **  
A user reports that their computer cannot access the internet.

**Troubleshooting Steps: **

1. Checked the network connection.
2. Used `ipconfig` to check the IP address.
3. Tested connectivity using `ping`.
4. Checked DNS resolution.
5. Renewed the IP address using DHCP.
6. Tested the internet connection again.

**As a Result:**  
The network connection was restored successfully.

---

### Scenario 2: Printer Not Printing

**Problem:**  
A user cannot print documents.

**Troubleshooting Steps: **

1. Checked the printer connection.
2. Verified that the printer was powered on.
3. Checked the print queue.
4. Restarted the Print Spooler service.
5. Verified the printer driver.
6. Printed a test page.

**As a Result: **  
The printer successfully printed the test page.

## What I Learned

Through this lab, I practiced following a structured troubleshooting process:

1. Identify the problem
2. Gather information
3. Test possible solutions
4. Verify the solution
5. Document the resolution

These skills are essential for providing effective IT Help Desk support.
